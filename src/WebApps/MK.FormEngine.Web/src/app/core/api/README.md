# NSwag API Client Generation

This directory contains the auto-generated Angular HTTP services and DTO models generated by **NSwag** from the backend OpenAPI/Swagger specification (`MK.FormEngine.API`).

## Usage

### 1. How to Generate / Refresh Clients

Whenever API endpoints, request DTOs, or response DTOs are added or modified in `MK.FormEngine.API`:

1. Start the backend API:
   ```bash
   dotnet run --project src/WebApps/MK.FormEngine.API
   # API running at http://localhost:5157
   ```

2. Generate client services in `MK.FormEngine.Web`:
   ```bash
   npm run api:generate
   ```

This will automatically refresh `src/app/core/api/api-client.generated.ts`.

### 2. Using Services in Angular Components

In any Angular component, service, or guard:

```typescript
import { Component, inject } from '@angular/core';
import { AuthClient, LoginCommand } from '@core/api'; // or relative import './core/api'

@Component({
  ...
})
export class LoginComponent {
  private readonly authClient = inject(AuthClient);

  login() {
    const command = new LoginCommand({ username: 'admin', password: '...' });
    this.authClient.login(command).subscribe({
      next: (response) => {
        console.log('Login result:', response);
      },
      error: (err) => {
        console.error('Login error:', err);
      }
    });
  }
}
```

### 3. Configuration

- `nswag.json` at the root of `MK.FormEngine.Web` configures client generation (Target: Angular, `InjectionToken`, RxJS 7).
- `API_BASE_URL` provider is configured in `app.config.ts` to dynamically resolve `AppConfigService.snapshot.apiBaseUrl`.
- OpenAPI `operationId`s are set in `Shared.Swagger` as `{ControllerName}_{ActionName}` (e.g. `FsmsTemplates_GetTemplates`). NSwag uses those as client method names. Do **not** rely on path-derived names like `templatesGET` / `templatesGET2` — those appear when `operationId` is missing and collide across controllers.

### 4. Avoiding `*GET2` / `*POST2` method names

NSwag uniquifies method names **across the whole generated file**. If two endpoints resolve to the same name (common when `operationId` is absent and both routes end with `/templates`), the second becomes `templatesGET2`.

**Do:** keep unique controller action names; rely on `CustomOperationIds` in Shared.Swagger; regenerate after API restarts.

**Do not:** hand-edit `api-client.generated.ts` to rename methods.
